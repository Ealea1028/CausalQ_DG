# Dataset contract

## AutoDL root

All datasets live below `/root/autodl-tmp/datasets`, configured by `CAUSALQ_DATA_ROOT`. Raw data never enters Git.

## Required Phase 3 layout

```text
/root/autodl-tmp/datasets/
├── gta5/
│   ├── images/
│   ├── labels/             # official/raw label IDs; preserved unchanged
│   └── labels_trainIds/    # generated by this project
└── cityscapes/
    ├── leftImg8bit/
    │   ├── train/
    │   └── val/
    └── gtFine/
        ├── train/
        └── val/
```

GTA5 images and labels must retain matching relative filenames. Cityscapes uses the official `*_leftImg8bit.png` and `*_gtFine_labelTrainIds.png` names.

## Label contract

- Common label space: Cityscapes 19 train IDs (`0..18`).
- Ignore index: `255`.
- GTA5 raw labels are mapped with the official Cityscapes label-ID-to-train-ID mapping.
- Conversion never overwrites `gta5/labels`; output goes to `gta5/labels_trainIds`.
- Existing converted files are skipped unless an explicit overwrite flag is supplied.

## Validation artifacts

`tools/check_datasets.py` emits a JSON report and saves paired image/colored-label previews under the configured output directory. The report distinguishes missing pairs, invalid train IDs, unreadable files, and image-mask size mismatches.
