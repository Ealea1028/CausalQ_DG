- **Anchor 稳定性。** UA 相对 U0、CA 相对 C0，在两个骨干上都降低了 Anchor 原始与 RMS 归一化方差。以 DINOv3 UA 对 U0 为例，归一化方差从 0.004914 降至 0.000578，Anchor joint RMS 从 0.760 升至 1.237，Residual joint RMS 从 0.114 升至 1.273。幅值和归一化方差同时变化，CA 的 Anchor 稳定性提升也没有伴随相对 C0 的目标 mIoU 提升。
- **Query 责任。** DINOv3 CA 的平均 slot 0 责任达 0.881，原图像素熵为 0.0178，低于 C0 的 0.5250。DINOv2 CA 的平均 slot 0 为 0.567，像素熵也从 C0 的 0.5488 降至 0.0680。这说明像素级选择更集中，即使数据集平均质量接近均分。slot 下标在独立模型间可能互换，单 seed 的汇总不足以判定整个模型塌缩。
- **B 系列。** B1–B3 的 Residual 结构性为零，RMS 归一化 Residual 方差为空。同类 slot 的 0.5 与零切换是结构性平局。B2/B3 的类别责任仍会随风格变化。按冻结路由的 readout effect 比较这些组，并另用 128 图×5 视图的主路径重算 on/off。D3 B2/B3 的平均 on−off 分别为 0.09889/0.10889，D2 为 0.10252/0.11006。D2 B2 的目标准确率增益没有延续到 B3。

## 原始特征与 LoRA 特征的联合 PCA

每个骨干独立拟合 6 套共同坐标，覆盖最终 Patch、CLS，以及第 6、12、18、24 层 Patch。每套以原始骨干和七个 L1 模型共八组等量参与。D3 的原始组从冻结 D3 U0 L0 的骨干提取，D2 直接使用原始 HPI P16 骨干。固定 128 张源图、五个视图，每图同坐标最多 32 个 Patch。每组各层 20,480 Patch 或 640 CLS。固定 seed 抽取 12 张图，各生成原图和 photo1 的对齐面板。验收通过 12 个基底、172 张图，原始数据在 Phase45 回传包的 `pca/`。

| 骨干 | 特征 | 共同 PC1–3 解释方差 | 七线原始/LoRA 平均余弦的范围 |
|---|---|---:|---:|
| DINOv3 | 最终 Patch | 31.71% | 0.5873–0.6095 |
| DINOv3 | CLS | 24.59% | 0.6949–0.7193 |
| DINOv2 P16 | 最终 Patch | 26.42% | 0.6725–0.6892 |

层 6、12、18 的 U0 对齐特征相对 L2 距离为 0，符合 LoRA 从索引 18 即第 19 层起注入。适配后的末端 Patch 与 CLS 都可观察到位移。例如 DINOv3 U0 的均值相对 L2 为 1.361 和 0.817，DINOv2 U0 为 0.822 和 0.893。余弦和相对 L2 来自原始高维匹配特征，坐标与 RGB 范围仅用于共享投影。路由后的特征作用由上节主路径指标记录。 [逐层解释方差、漂移和样式方差](joint_pca.csv)

## 冻结、训练和算力

- **配置与可恢复性。** DINOv3 ViT-L/16 和 DINOv2 ViT-L HPI P16 独立加载。在两者末 6 个 block 的 Q/V 投影注入 rank 4、alpha 4 LoRA，每个骨干新增 98,304 个可训练参数。骨干原权重冻结，CausalQ 分割头照常训练。Phase39 的真实权重验收包含 Patch/CLS 形状、LoRA 梯度、冻结权重 digest 和零增量检查。Phase40/42 保存和恢复验证覆盖 LoRA、优化器、RNG、源游标。D3 U0 L0 作为已完成的对照，没有用于初始化 L1。 [Phase39 验收记录](../../experiments/LORA_CAUSALQ_1114/phase39_acceptance.json) · [Phase40 恢复记录](../../experiments/LORA_CAUSALQ_1114/phase40_resume_acceptance.json)
- **HPI 配方。** AdamW 基础 LR 1e−4、weight decay 1e−5、norm 无衰减、1,500 步 warmup、poly power 0.9、最小 LR 1e−6、梯度范数裁剪 1。GTA5 输入 512×512，每次更新有效 batch 8，由两个 microbatch 4 累积。14 个最终端点累计 560,000 次正式更新，其中 D3 保留早期实例上的 3,238 步，后在 vGPU-48GB 续跑。
- **正式训练。** vGPU 实际报告 NVIDIA GeForce RTX 4090，47.37 GiB 可见显存。四线 D3 和 D2 的稳态中位聚合吞吐分别为 24.29 和 26.30 源图/s，相对各自单 UA 的 21.90 和 23.10 源图/s。通过窗口分别为 428/429、403/404，CA 末段独立完成。B1/B2/B3 双线稳态中位数分别为 27.70、27.69、26.84 源图/s，通过 194/194、194/194、199/199 个窗口。上述训练稳态 GPU 中位活动率均为 100%。
- **诊断与推理。** Phase45 初次启动中断，GPU 中位活动率 0%，复用其 530 条有效 D3 UA 记录。改为设备端 FP64 统计后，完成版历时 9,397 秒，各模型 GPU 中位活动率 72–96%，CUDA 峰值保留显存约 4.86–6.73 GiB。Phase46 历时 1,133 秒，整阶段约 6.62 图次/s。每模型使用 6 个数据加载进程，耗时 70.24–76.12 秒，GPU 中位活动率 79.5–81%，CUDA 峰值保留显存约 2.23–2.50 GiB。 [逐模型用时、GPU 活动率和参数量](models.csv)
