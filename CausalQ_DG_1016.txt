==================================================
一、项目最终目标
==================================================

本阶段不是简单继续堆叠模块，而是围绕当前 CausalQ 已有实验结果，
重新组织研究问题，使项目最终能够形成一条具有论文价值的实验逻辑：

    Multi-Query Representation
            ↓
    Class-shared / Within-class Decomposition
            ↓
    Query Effect Decomposition
            ↓
    不同 Query Component 的 Effect Heterogeneity
            ↓
    Selective Effect Stabilization
            ↓
    GTA5 → Cityscapes Domain Generalization

核心工作假设：

    一个类别并非只有一个语义模式；
    因此 class-specific Query Bank 可以表示：

        class-shared semantic component
                     +
        within-class variation

    但是这些 component 的预测作用不一定都应该跨 domain 保持完全不变。

因此：

    不应该：
        对所有 Query Effect 强制一致

    而应该：
        对 class-shared Anchor Effect 强一致
        对 within-class Residual Effect 保留自由度

暂定研究名称：

    Causal Query Decomposition

或者：

    Causal Query Decomposition +
    Component-wise Effect Distillation

注意：

这个名称只是工作名称。
不要在代码中大规模重命名现有 CausalQ 组件。

==================================================
十、核心科学问题
==================================================

新版本 CausalQ 不再试图证明：

    Query = causal factor

也不声称：

    Anchor = true causal variable

正确表述：

    Anchor / Residual
    是 model-internal semantic decomposition。

Query intervention：

    do(Qc = 0)

是：

    model-internal intervention

而不是：

    real-world causal intervention。

Style intervention：

    original
        ↓
    photometric style

只是：

    appearance/domain nuisance 的 proxy intervention

不能声称：

    Fourier / Photometric = true causal intervention


==================================================
十一、建议的新因果框架
==================================================

真实世界 causal graph：

                 C
              /     \
             ↓       ↓
            X         Y
             ↑
             |
             S

其中：

    C = stable semantic/content factor
    S = style/domain factor
    X = observed image
    Y = ground-truth segmentation

即：

    C → X ← S
    C → Y

不要画：

    Ŷ → Y

因为预测结果不是 ground-truth 的原因。


模型计算图：

                 X
                 ↓
             DINOv3 F
              /     \
             ↓       ↓
        Base Path   Query Path
                       ↑
                  Query Bank
                       |
               Anchor + Residual
                       |
                       ↓
                 Query logits
                       |
                       ↓
                    Ŷq
              ↙              ↘
          Base Ŷb           Query Ŷq
                \           /
                 \         /
                   Final Ŷ


新的 Query decomposition：

                Query qc,r
                    |
            ┌───────┴────────┐
            ↓                ↓
         Anchor           Residual
            ↓                ↓
     shared component   within-class
                         variation


研究假设：

    Anchor Effect
        ↓
    更稳定

    Residual Effect
        ↓
    允许存在跨-style variation


==================================================
十二、核心结构修改
==================================================

当前：

    q(c,r) = a(c) + e(c,r)

修改为：

    e_bar(c) = mean_r e(c,r)

    e_tilde(c,r)
        =
    e(c,r) - e_bar(c)

    q(c,r)
        =
    a(c) + e_tilde(c,r)

因此：

    mean_r e_tilde(c,r) = 0

从而：

    mean_r q(c,r) = a(c)

这使：

    class_anchor

具有明确的参数化含义：

    class-shared Query component

十三、具体代码修改
==================================================

优先修改：

    causalq/models/query_segmentor.py

不要新建完全独立的 Query Bank。

直接修改：

    GroupedCausalQueryBank

建议：

    def forward(self, batch_size):
        residuals = self.query_residuals
        residuals = residuals - residuals.mean(
            dim=1,
            keepdim=True
        )

        )

同时增加：

    get_centered_residuals()

不要删除：

    get_query_residuals()

因为旧实验仍然需要。

==================================================
十六、Anchor-only Counterfactual
==================================================

这是新版本最重要的实现。

当前 Query：

    q(c,r)
      =
    a(c) + e_tilde(c,r)

定义：

    Q_full(c)
      =
    {q(c,1), ..., q(c,R)}

Anchor-only Query：

    Q_anchor(c)
      =
    {a(c), ..., a(c)}

即：

    residual = 0

注意：

这是一个 proposed model-internal intervention，
不是已有 CausalQ 的原始实现。

实现：

    anchor_queries =
        anchor.unsqueeze(2).expand(
            B, C, R, D
        )

然后通过相同 Query Residual Head：

    Z_full
    Z_anchor
    Z_zero


==================================================
十七、三个 Query Effect
==================================================

对于每一个 style view s：

1. Full Query：

    Z_full^s

2. Zero Query：

    Z_zero^s

    do(Qc = 0)

3. Anchor-only：

    Z_anchor^s

定义：

    E_full^s
      =
    Z_full^s - Z_zero^s

定义：

    E_anchor^s
      =
    Z_anchor^s - Z_zero^s

定义：

    E_residual^s
      =
    E_full^s - E_anchor^s

注意：

E_residual 是 output-space residual contribution：

    E_full
    =
    E_anchor
    +
    E_residual

这是严格成立的定义。

不要声称：

    E_residual
    =
    “纯 residual 的独立 causal effect”

因为 Query head 中存在 normalization / logsumexp 等非线性。

正确名称：

    residual contribution

或者：

    residual-induced effect component


==================================================
十八、Anchor-CQE
==================================================

主方法：

    Cross-Style Anchor Effect Consistency

对于：

    original
    photometric

分别得到：

    E_anchor^orig
    E_anchor^photo

定义：

    L_anchor_CQE
        =
    D(
        normalize(E_anchor^photo),
        stopgrad(
            normalize(E_anchor^orig)
        )
    )

其中：

    D = SmoothL1

保持当前 CQE 的：

    valid-pixel
    class-present

mask 逻辑。

不要改变：

    Style Intervention strength

不要重新设计 Style Bank。


==================================================
十九、为什么不对 Residual 强制一致
==================================================

核心假设：

    Anchor
        =
    class-shared component

    Residual
        =
    within-class variation

因此：

    Anchor Effect
        ↓
    强跨-style consistency

而：

    Residual Effect
        ↓
    不进行硬一致性约束

原因：

当前实验已经说明：

    Effect Variance ↓↓↓

并不自动意味着：

    DG mIoU ↑

原 CQE 的问题可能就是：

    把有用 variation
    当成 nuisance variation

因此：

    Stable ≠ Useful

新方法：

    Stable shared component
    +
    Preserved useful variation


==================================================
二十、Query Responsibility Diagnostic
==================================================

不要把 Query 是否“有不同语义”直接写死。

需要做实验验证。

对每一个 class：

    score(c,r,p)

计算：

    rho(c,r,p)
      =
    softmax_r(
        score(c,r,p)
    )

即：

    Query responsibility

注意：

responsibility 是：

    competition / attribution signal

不是：

    causal effect

不能混用。


==================================================
二十一、Responsibility 指标
==================================================

至少记录：

1. Mean responsibility

    R(c,r)

2. Responsibility entropy

    H(c)

3. Query pair similarity

    cosine(q(c,1), q(c,2))

4. Residual norm

    ||e_tilde(c,r)||

5. Anchor norm

    ||a(c)||

6. Anchor / residual norm ratio

    ||a|| / mean(||e||)

7. Cross-style responsibility variance

8. Query activation rate

9. Query contribution

这些结果用于回答：

    R=2 是否真的产生了
    类内不同模式？

如果没有：

    R=2 只是增加参数容量

那么论文不能声称：

    “two queries learn two semantic modes”。


==================================================
二十二、Effect Localization
==================================================

对于 class c：

    Ωc = pixels whose GT == c

计算：

    Anchor Effect Inside

        mean |E_anchor,c(p)|
        p ∈ Ωc

以及：

    Anchor Effect Outside

        mean |E_anchor,c(p)|
        p ∉ Ωc

定义：

    Localization Ratio

        Inside / (Outside + ε)

同时记录：

    Effect Energy

        mean |E_anchor|

以及：

    Effect Variance

        variance across style views


==================================================
二十三、Effect Utility / Necessity
==================================================

防止出现：

    Effect → 0
    Variance → 0

但模型实际上没有利用 Query。

在分析阶段必须计算：

    Query Necessity

即：

    factual prediction
        vs
    do(Qc = 0)

对于 GT class：

    Δc(p)
      =
    Z_fact,c(p)
    -
    Z_null,c(p)

重点统计：

    GT region
    non-GT region

如果：

    Δc ≈ 0

而：

    mIoU 正常

说明 Query 可能不是模型真正依赖的机制。

如果：

    Δc 明显 > 0

且：

    zero intervention
    导致 GT prediction degradation

则 Query 的模型内部必要性证据更强。


==================================================
二十四、可选 Sufficiency Loss
==================================================

第一轮不要加入。

只有在 M3 出现：

    Anchor effect collapse

时再加入。

定义：

    L_suf_anchor

=
    mean over p∈Ωc
    max(
        0,
        m - E_anchor,c(p)
    )

注意：

这个 loss 的目的不是：

    让 Anchor 单独完成整个 segmentation

而是：

    保证 Anchor 对正确 class
    有非平凡的正向作用。

默认：

    不直接启用

先做 diagnostic。


==================================================
二十五、Specificity Loss
==================================================

同样先作为 diagnostic。

定义：

    L_spec_anchor

=
    mean over p∉Ωc
    |E_anchor,c(p)|

或者：

    max(
        0,
        E_anchor,c(p) - m_neg
    )

目的：

    Anchor effect
    应主要落在对应 semantic region

而不是：

    整张图都产生巨大 effect。

    initialization ablation
    future branch

不能成为第一版新方法主体。

六十五、论文导向的最终判断标准
==================================================

项目最终能否成为论文，不取决于：

    “最终 mIoU 是不是特别高”

而取决于是否能够形成以下完整逻辑：

Step 1：

    Multi-query improves segmentation.

Step 2：

    Query Bank contains a shared component
    and within-class variation.

Step 3：

    Centered parameterization makes this
    decomposition identifiable.

Step 4：

    Different components have different
    cross-style effect stability.

Step 5：

    Naive full-effect consistency
    over-constrains useful variation.

Step 6：

    Selective stabilization of the class-shared
    component improves domain generalization.

Step 7：

    This improves unseen-domain
    GTA5 → Cityscapes performance.

如果能够形成：

    representation evidence
    +
    intervention evidence
    +
    effect evidence
    +
    ablation evidence
    +
    target generalization evidence

那么 CausalQ 才真正从：

    “一个 Query-based segmentation trick”

升级成：

    “关于 Query-mediated prediction mechanism
     在 domain shift 下如何稳定的研究”。
